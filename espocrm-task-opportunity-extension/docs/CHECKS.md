# Локальные результаты, 11.11.2026

Проверен только отдельный комплект. CRM/LXC/Proxmox, рабочая БД, отправка,
установка и создание реальных сделок не выполнялись.

Среда проверки: PHP CLI 8.4.27 с `-n`, Node.js и Python 3. PHP и необходимые
системные библиотеки распакованы только в `/tmp`, в систему не устанавливались.
У расширения нет внешних библиотек. Исходники EspoCRM 10.0.6 прочитаны из
публичного тега в `/tmp`; рабочая CRM для сверки не использовалась.

Команда разработки:

```bash
LD_LIBRARY_PATH=/tmp/lr-php-runtime/usr/lib/x86_64-linux-gnu PHP_BIN=/tmp/lr-php-runtime/usr/bin/php8.4 ./check.sh
```

Результаты — PASS:

- PHP lint всех PHP-файлов; `node --check` обоих JS-файлов.
- Policy: точные Task/marker/result, parent/account fallback и конфликт,
  назначение, отсутствие defaults суммы/даты, обязательные пользовательские значения.
- Настоящий TaskOpportunityAction с API/ORM doubles: GET без сделки,
  rollback при ошибке, восемь одновременных процессов → count=1, единый ID,
  повтор после отброшенного ответа, ACL, подмена Account/User/stage, soft delete.
- Настоящий beforeSave hook: обычные сделки, неизменность source,
  запрет подменённых связей, последующее редактирование без смены source.
- Настоящий SchemaGuard с PDO doubles: InnoDB, отказ при другом driver,
  отсутствующем/неуникальном/составном индексе (source + deleted).
- Настоящий CLI-установщик на временном каталоге: plan без записи,
  сохранность пользовательского поля и stage options, повтор без изменений,
  отказ при конфликте, disable/re-enable без удаления схемы, отказ отката после
  посторонней правки, полный откат до точных исходных байтов.
- JSON-синтаксис всех патчей, frontend-обработчик и URL сохранения,
  очистка amount/closeDate.
- Сборка tar.gz, SHA-256 архива и файлов, проверки из распакованного архива.

Изолированный файловый transaction double проверяет алгоритм обработчика при
конкуренции, **не доказывает** реализацию блокировок InnoDB. SchemaGuard doubles
также не являются проверкой живой схемы. Реальные rebuild, DI/hook discovery,
metadata merge платформы, SQL и ACL конкретной CRM, браузер, обязательные custom
fields/формулы и сохранность deployment при пересоздании требуют приёмки на клоне
по README. Версия другого PHP/ОС не тестировалась.
