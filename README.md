# LexRadar

LexRadar — система автоматизированного юридико-технического аудита сайтов на соответствие требованиям законодательства РФ о персональных данных.

## Статус

Проект находится на стадии разработки MVP.

## Принцип работы

Сбор доказательств → независимые проверки → юридическая верификация → решение GO / NURTURE / HOLD / STOP → проверка человеком.
