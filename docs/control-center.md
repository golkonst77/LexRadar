# LexRadar Control Center

Минимальный локальный веб-сервер на стандартной библиотеке Python.
Установка пакета LexRadar и дополнительных зависимостей не требуется.
Из корня репозитория запустите:

```bash
python3 control_center.py
```

Откройте http://127.0.0.1:8080. Другой порт: `python3 control_center.py --port 8090`.
Остановка: Ctrl+C. Сервер слушает только локальный адрес `127.0.0.1`.

Доступные маршруты:

- `GET /` — русскоязычная главная страница с тёмным интерфейсом.
- `GET /organizations` — список организаций, поиск по названию, сайту и ИНН,
  фильтр правового статуса и страницы по 20 записей.
- `GET /organizations/<id>` — сохранённые сведения об организации и источник.
- `GET /health` — JSON `{"status": "ok"}`, проверяет доступность самого сервера.
- `GET /api/status` — JSON со статусом сервера, режимом `read_only` и флагами
  `analysis_enabled: false`, `mailing_enabled: false`.

Неизвестные маршруты возвращают 404. Проекты, отчёты и настройки пока представлены
заглушками на главной странице. Сервер не импортирует анализатор LexRadar, не запускает анализ, рассылку
или обращения к внешним сервисам, включая EspoCRM. Результаты открываются только
для чтения; базы данных, индекса на диске и записи в результаты нет.
Это локальный сервер разработки без авторизации, не предназначенный для публикации
в интернете. Статус API описывает только этот процесс.

Короткий тест проверяет обработку HTTP-запросов в памяти, без открытия сокета:

```bash
python3 -m unittest discover -s tests -p 'test_control_center.py' -v
```

## Организации из существующих результатов

По умолчанию каталог результатов — текущий рабочий каталог (`Path.cwd()`).
Для результатов из другого места:

```bash
python3 control_center.py --results-dir /absolute/path/to/results --port 8090
```

Откройте http://127.0.0.1:8090/organizations. Каталог можно указать как корень
нескольких запусков, так и отдельный результат первичного аудита.
Чтение повторяется при запросе: новые результаты видны после обновления страницы.
Отсутствующий или пустой каталог даёт пустое состояние без демонстрационных данных.

Поддерживаются существующие форматы из `src/lexradar/primary/models.py` и
`src/lexradar/primary/cli.py`, описанные в
[методологии первичного аудита](primary-audit-methodology.md):

- `audit.json`, `schema_version=primary-audit-0.1`: массив `organizations`,
  сайт `target_url`, правовой статус `legal_status`.
- `organizations.json`, `audience=internal_only`: массив `rows`, сайты из
  `identification_sources[].url`. Статус при отсутствии `legal_status` — «Не указан».

Если оба файла находятся рядом, используется только `audit.json`, чтобы не удваивать
организации. Повреждённый аудит не заменяется потенциально устаревшей матрицей.
Название и ИНН берутся из полей `name` и `inn`; отсутствующие сведения не угадываются.
«Не подтверждён» означает `legal_status=not_confirmed`, а не подтверждённое нарушение.
Карточка показывает исходную строку организации с ограничениями и источниками.
Идентификатор URL — SHA-256 относительного пути файла и исходного ID организации.
Одинаковые локальные ID из разных запусков не конфликтуют; разные запуски показаны
отдельно, автоматического объединения юридических лиц нет. Перенос результата
внутри каталога меняет ссылку на карточку.

Поиск `q` нечувствителен к регистру и ищет подстроку; `status` фильтрует точное
сохранённое значение. Ссылки пагинации сохраняют оба параметра. Неверная страница
заменяется допустимой. Пример: `/organizations?q=clinic&status=not_confirmed&page=2`.
Неизвестный ID карточки возвращает 404.

Каталоги `examples`, `tests`, `docs`, `node_modules`, `__pycache__` и скрытые каталоги
исключены из рекурсивного обхода. Поэтому примеры репозитория не появляются как
рабочие организации. Для явного просмотра примера можно указать сам каталог
`examples/primary-audit/result` через `--results-dir`; это синтетическая фикстура.
Символьные ссылки, включая ссылки в пути корня, не читаются; произвольных файловых
маршрутов нет. Читаются только обычные файлы с двумя указанными именами размером
не более 8 МБ. Ошибки чтения, JSON и неподдерживаемый формат отображаются общим
предупреждением без раскрытия абсолютных путей или содержимого файлов.
Ссылки из результатов выводятся текстом, HTML экранируется.

Ограничения: чтение использует POSIX `os.fwalk`, `dir_fd` и `O_NOFOLLOW` (Linux).
Все результаты просматриваются при каждом запросе, поэтому для большого архива
указывайте каталог нужных запусков. Контрольный центр показывает только сохранённые
результаты первичного аудита, не состояние процессов и не CRM-статусы.
