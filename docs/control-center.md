# LexRadar Control Center

Минимальный локальный веб-сервер на стандартной библиотеке Python.
Установка пакета LexRadar и дополнительных зависимостей не требуется.
Из корня репозитория запустите:

```bash
python3 control_center.py
```

Откройте http://127.0.0.1:8080. Другой порт: `python3 control_center.py --port 8090`.
Остановка: Ctrl+C. Сервер слушает только локальный адрес `127.0.0.1`.

Доступные маршруты:

- `GET /` — русскоязычная главная страница с тёмным интерфейсом.
- `GET /health` — JSON `{"status": "ok"}`, проверяет доступность самого сервера.
- `GET /api/status` — JSON со статусом сервера, режимом `read_only` и флагами
  `analysis_enabled: false`, `mailing_enabled: false`.

Неизвестные маршруты возвращают 404. Проекты, отчёты и настройки пока представлены
заглушками на главной странице. Сервер не импортирует модули LexRadar, не читает
данные проектов, не запускает анализ, рассылку или обращения к внешним сервисам.
Это локальный сервер разработки без авторизации, не предназначенный для публикации
в интернете. Статус API описывает только этот процесс.

Короткий тест проверяет обработку HTTP-запросов в памяти, без открытия сокета:

```bash
python3 -m unittest discover -s tests -p 'test_control_center.py' -v
```
