# Sprint 1: покрытие сохранённых материалов

База разработки: main `047deedc58e7d9e021c9304d4ce38de2037bb968`.
Изменения PR #17 не включены.

## Реализованные изменения

- Primary распределяет текстовый бюджет между смысловыми блоками исходного HTML.
  Сначала идут блоки с признаками существенных раскрытий, затем обычный текст,
  затем навигация. Внутри группы используется равномерное распределение с
  перераспределением остатка от коротких блоков, а не порядок обхода DOM.
  Обрезанный блок предоставляет непрерывный фрагмент вокруг первого признака.
  Цитаты указывают исходный артефакт и область разбора; пропуски явно ограничивают
  затронутые этапы. Сохранённые оригиналы и производные не переписываются.
- Collector приоритизирует PDF по подписям, путям и контексту страницы.
  Решения о выборе и пропусках записываются в журнал. См. `collector.md`.
- Постраничное PDF-извлечение сохраняет явные состояния непрочитанных страниц,
  включая диапазон после предела подробной инвентаризации. Windows поддерживает
  изолированный worker с ограничением памяти и процессорного времени.
- Общий предел входного пакета настраивается в `AnalysisConfig.max_input_bytes`
  (также наследуется `VerifierConfig`) до 20 000 000 байт. CLI локального Primary,
  preflight и локальных проверок используют `--max-input-bytes`. Значения по умолчанию
  не повышены. Лимит измеряет UTF-8-байты полного сериализованного пакета; превышение
  сообщает размеры и прекращает работу без усечения. Предварительное разрешение
  передачи остаётся привязанным к точному хешу пакета. Лимит manifest — 20 MB.
- Автоматические регрессии проверяют независимость от порядка, поздние раскрытия,
  приоритет непрозрачных PDF-ссылок, пределы текста/страниц и границы пакета.

## Приёмка

Разработка и синтетические проверки выполняются без досье scz.ru.
Единственный заблокированный пункт приёмки — контрольный прогон сохранённого
досье scz.ru и достоверное сравнение находок «до/после». Синтетические тесты
не подтверждают устранение потерь на scz.ru. Main не изменяется, production deploy
не выполняется.

Конечный бюджет не гарантирует чтение всех блоков; эвристики могут пропустить
нетипичные раскрытия. Сканированные страницы требуют отдельного OCR/визуального
чтения. Неизвестный счёт страниц при полной ошибке PDF остаётся неизвестным.
Юридическая применимость и полнота сайта независимо не установлены.
