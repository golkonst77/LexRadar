# SYNTHETIC DEMO №114

Только учебная организация и вымышленные домены `.example.invalid`.

- `review.html` — исходная очередь из трёх REVIEW-карточек.
- `reviewed.html` — результат автоматизированного воспроизведения действий оператора в браузере: CONFIRM / REJECT / NEED_MORE_EVIDENCE. Это тестовый сценарий, не подпись юриста.
- `proposal.html` — обезличенный DRAFT: только первая подтверждённая карточка. Цены, скидка, сроки и оформление v2.4 сохранены; контакты исполнителя заменены.
- `operator-journal.json` — синтетические связанные события и итог GO только для черновика.
- `evidence/` — безопасный текст двух синтетических документов; исходный код сайта не исполняется.

GitHub показывает HTML как исходный текст. Для интерактивного просмотра скачать эту папку, сохранив структуру, и открыть `review.html` или `reviewed.html` локально. Внешние ресурсы, сервер, CDN, AI и отправка отсутствуют. Любой экспорт из страницы — неподтверждённый ввод; реальный локальный CLI повторно проверяет исходное досье. Само досье, SQLite и approved template в публикацию не входят.
