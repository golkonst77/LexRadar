## Доказательные находки

Все четыре цитаты заново сверены с байтами сохранённых оригиналов, а не только
с ответом AI или текстом первичного анализа. PDF повторно извлечены через pypdf
с указанием страницы. У каждого наблюдения есть URL, путь оригинала, SHA256,
точная цитата и координата. Цитаты HTML показаны как текст, исполняемый код не включён.

**MedicPro:**

1. На сохранённой странице приёма терапевта у checkbox согласия задан
   `checked="checked"` (HTML `page-0002`, строка 3275). Это основание уточнить
   начальное состояние и действие пользователя; реальное состояние после JS,
   отправка и нарушение не установлены.
2. Там же есть `textarea` с подсказкой «Ваш вопрос» (строка 3342). Это основание
   согласовать назначение свободного текста, получателей и пояснения к полю.
   Фактический ввод медицинских сведений пациентами не утверждается.

**Клиника Фомина:**

1. В PDF политики, страница 1, п. 1.2 прямо указан калужский домен.
   Политика существует: предлагается сопоставление с реальными процессами и
   адресная редакция при необходимости, а не продажа «отсутствующей политики».
2. В PDF согласия, страница 1, прямо названы третьи лица и лабораторные и иные
   исследования. Связь этого медицинского согласия с действием в форме записи
   не доказана. Предлагается разделение подтверждённых сценариев и карта документов.

Ни одна находка не названа доказанным нарушением. Ссылки на нормы, штрафы,
«гарантии соответствия» и мнимые обязательства не добавлялись. Актуальные нормы
и применимость в рамках этого запуска не проверялись.

## Мусор и повторы

Добавлен отдельный офлайн-слой `python -m lexradar.review_bundle` поверх сохранённого
результата MVP. Он создаёт короткий аудит, КП, HTML доказательств, JSON-протокол и
манифест контрольных сумм. Выбор находок задаётся проверяемым редакторским brief,
а не синтетическим AI. Исходный генератор №45 и оригиналы не перезаписываются.
Коммерческий слой вызывается явно по инструкции; старый `mvp` сам на него не переключается.

- MedicPro: **21 вхождение → 3 семейства разметки**. Скрытые поля и повторение
  каждого шаблона на каждой странице убраны из основного текста.
- Фомина: **11 вхождений → 1 поисковое семейство** с полем `query`.
  Они не выдаются за 11 форм записи или за доказательство отсутствия записи.
- Группировка учитывает поля, checked/required, ссылки, контекст, объявленный
  маршрут/метод и полноту разбора. Различающиеся согласия и покрытие не склеиваются.
  Семейства разметки не объявляются уникальными процессами обработки.
- Сырые массивы ошибок парсера, JSON selection и синтетические AI-наблюдения
  не попадают в КП. Существенные ограничения изложены понятными фразами один раз.
  В протоколе сохранены члены групп со всеми исходными URL и координатами.
- Недоступное извлечение третьего PDF Фомина отмечено как пробел сбора,
  без утверждения об отсутствии документа.

Генератор проверяет все зарегистрированные SHA256 оригиналов, соответствие URL
brief и досье, точное присутствие цитаты и страницу PDF. Ошибка останавливает
генерацию до создания выхода. Ссылки и текст экранируются; выход должен быть новым.
HTML не загружает внешние скрипты, шрифты, изображения или стили.
В `runs-046/validation.json` — проверка манифестов, ссылок и состава пакета.

### Фактический результат commit/push

Коммит и push **не выполнены из-за ограничения среды**, а не из-за отсутствия
авторизации пользователя. Выполнена попытка `git add` только новых файлов №46.
Git завершился до изменения индекса:

```text
fatal: Unable to create '/home/golkonst/src/LexRadar/.git/worktrees/LexRadar-compact/index.lock': Read-only file system
```

Git-каталог worktree находится вне разрешённых записываемых директорий; профиль
разрешений не допускает повышение прав. Push без нового проверенного коммита не
выполнялся. Ветка осталась `feat/compact-ai-audit-mvp`, `main` не затронут.
Изменения доступны для просмотра в рабочем дереве. После предоставления среды с
записываемым Git-каталогом достаточно добавить только следующие пути, просмотреть
staged diff и выполнить commit/push в эту же ветку:

```bash
git add -- src/lexradar/review_bundle.py tests/test_review_bundle.py docs/codex-reports/codex-046-report.md runs-046
git diff --cached --stat
git diff --cached --check
git commit -m "feat: add evidence-checked commercial review bundles for task 046"
git push origin HEAD:feat/compact-ai-audit-mvp
```

Предшествующие грязные файлы не добавлять. Полные локальные `.log` исключены
правилом `runs-046/.gitignore`.
