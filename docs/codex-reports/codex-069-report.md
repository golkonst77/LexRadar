## Изменения

Добавлен отдельный `single-a-v2.txt`, старый промпт и его штатный маршрут сохранены.
Сначала промпт требует извлечения текстовых проблем, затем отдельной квалификации.
В действующих полях JSON размещаются точная цитата, фактическое наблюдение,
правовая гипотеза, условия применимости, доказанность и конкретная возможная
услуга ИП Голубева. Включены оператор, цели, конкретность политики, признаки
шаблона, стоматологический контекст, обращения субъекта, формы, согласия, сроки,
получатели, безопасность и границы медицинских требований. Три указанные
оператором фразы проверяются как кандидаты, а не готовые нарушения.

Промпт запрещает выдумывать нормы, автоматически применять требования письменного
согласия к обычным формам и требовать полного публичного раскрытия технических
мер. Девять coverage и схема JSON сохранены. Критерии commercial/qualify,
проверка цитат и барьер независимой правовой проверки не изменены.

## Единственная сетевая попытка

Перед сетью исправлена локальная ошибка запуска через `-m`: идентичность функции
не совпадала с проверяемым объектом. Этот запуск завершился до создания каталога
анализа и до post; его нельзя считать запросом к DeepSeek. Добавлен регрессионный
тест канонической точки входа.

Затем выполнен один post через штатный OpenRouterProvider/OpenRouterTransport:

| Промпт SHA256 | `e1e5adb0a4cb5d92a262a27b17e82644927599e2b6593f2c9b404059929671da` |
| Консервативный резерв | $0.070648 |
| Фактическая стоимость | **Неизвестна: usage не получен** |

| HTTP / полученные байты | статус отсутствует / 0 |

Резерв нельзя считать фактическим списанием или объявлять расход нулевым.
В логе request_sent=true означает передачу управления транспорту, а не
подтверждение приёма запроса сервисом или генерации модели. Утверждать, что был
успешный платный вызов, нельзя. Повторного запроса, проверки баланса или запроса
usage не выполнялось. Ключ загружен по документированному штатному пути только
в память процесса, в argv/вывод/артефакты не помещён.

Навык cloud-environment-runtime прочитан. Инструмент environment_status и
`/etc/codex/network-policy.json` в сессии недоступны. Сетевые настройки не менялись,
обход ограничений не выполнялся. Блокер — доступ к OpenRouter в текущем окружении;
после исправления доступа нужен отдельно разрешённый новый эксперимент.
