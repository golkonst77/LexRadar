## Следующий шаг

Нужно выполнить те же два бесплатных GET из окружения с доступом к
OpenRouter, используя существующий ключ, без повторной генерации.
Сначала сохранить metadata, затем проверить content. При 403 потребуется
экспорт сохранённого output из OpenRouter Logs либо доступ владельца
через management key; в этом задании новый ключ не создавался.
При доступном completion сохранить его приватно отдельно от исходных
артефактов, сопоставить input с пакетом/prompt, метаданные модели,
провайдера, finish_reason, usage и вызвать штатный `validate_compact`.
Отсутствие сохранённого текста можно фиксировать только по фактическому
результату доступа, а не по нынешней DNS-ошибке.

Если сервис подтвердит утрату текста, восстановление этой генерации
невозможно; новая генерация требует отдельного решения пользователя.
Ledger, approval и защиты первой попытки при этом не сбрасывать.
