1. Существующий CLI сборщика запущен через `from lexradar.cli import main; main()`

   интервалом 2 секунды. Chromium завершился до сетевого обхода:
   `TargetClosedError`, `sandbox_host_linux.cc:41`, `shutdown: Operation not permitted`.
   Лог: `runs-097/collection-cli.log`; журнал и summary: `runs-097/full/crawl/`.
2. Выполнена отдельная попытка существующего `collect(..., static_only=True)`
   в новом `runs-097/full-static` с теми же лимитами. Это предусмотренный
   сборщиком режим без браузера, визуальных доказательств и JavaScript.
   Сетевая политика, robots, TLS, DNS/IP-защита и лимиты не изменялись.
   Получение `https://kaluga-med.ru/robots.txt` завершилось `DNS resolution failed`.
   Сборщик штатно остановился с `robots_unavailable`, политика `deny_all`.
   Зарегистрирована 1 попытка robots-запроса, отправленных HTTP-запросов 0.
   Причина не доказывает недоступность сайта для других сетей.

Сначала проверены также модульные точки входа: `python -m lexradar.cli` не
вызывает main, у `python -m lexradar` отсутствует __main__. Эти вызовы не собирали
данные; их отдельные логи сохранены. Ни один существовавший до №97 файл результатов
не перезаписывался. Рабочая точка входа CLI использована в попытке 1.
