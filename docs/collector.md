# Evidence Collector v0.2

Collector — независимый поставщик технических наблюдений. Он не создаёт
LegalFinding, AuditorResult, GatewayDecision или юридическое заключение.
Команда v0.1 `lexradar examples/input.json` остаётся совместимой.

## Запуск

```bash
python -m pip install -e '.[dev]'
python -m playwright install --with-deps chromium
lexradar collect https://clinic.example --output work/audit --max-pages 10 --max-documents 10 --timeout 10
```

`.example` — демонстрационный домен: замените его на разрешённый публичный сайт.
Каталог результата должен быть новым: существующий каталог не перезаписывается.
Для установленного системного Chromium можно задать `LEXRADAR_CHROMIUM_PATH`.
`collection.json` содержит страницы, документы, формы, извлечённые реквизиты,
доказательства, ограничения и предупреждения. `artifacts/` содержит оригинальный
HTML, видимый текст, PNG страницы и форм, PDF. Пути относительные, хеши SHA-256
вычислены по фактическим сохранённым байтам. `collection.json` не входит в собственный хеш.

```python
from pathlib import Path
from lexradar.collector.models import CollectionResult
from lexradar.collector.artifacts import verify_integrity

result = CollectionResult.model_validate_json(Path("work/audit/collection.json").read_text())
issues = verify_integrity(result, Path("work/audit"))
assert not issues, issues
```

Настройки лимитов представлены в `examples/collector-limits.json`, пример
контракта результата — `examples/collection.json` (синтетический недоступный сайт).
Полный работающий пример — локальная HTML-фикстура и тестовый HTTP-сервер в tests/.

## Поведение и безопасность

Последовательный обход с устойчивой сортировкой ссылок (сначала тематические),
удалением URL-фрагментов и дедупликацией. Область обхода — строго тот же origin
(схема, hostname, порт); переход на другой origin, включая www и HTTP→HTTPS,
блокируется. Указывайте сразу канонический HTTPS-адрес. Перенаправления проверяются
по одному, без автоматического следования и без передачи cookies.

Разрешён только GET к HTTP(S) без URL-credentials. Запрещены local/internal имена
и все адреса, которые ipaddress не считает глобальными: loopback, private,
link-local, metadata, reserved, IPv6 local. Проверяются все DNS-ответы; соединение
закрепляется за проверенным IP, TLS проверяет сертификат исходного hostname.
Это закрывает DNS rebinding между проверкой и подключением. DNS, запросы,
перенаправления, число страниц и документов, размер файла и суммарные загрузки
ограничены. Артефакты имеют отдельный общий бюджет. Лимиты можно настроить через
`Limits` в Python; основные параметры доступны CLI. Лимит PDF-страниц также ограничен.

Транспорт не обходит обязательный proxy: при наличии HTTP(S)_PROXY он отказывает
в публичной загрузке с явной причиной. Для сетей, требующих proxy, понадобится
отдельный доверенный адаптер, обеспечивающий IP-проверку на стороне egress.
Не удаляйте настройки proxy для обхода политики среды. В этой облачной среде
публичные сайты не сканировались; тесты используют только локальный fixture transport.
В production CLI нет переключателя разрешения частных адресов.

Playwright открывает исходный URL, но получает уже проверенные байты HTML через
route.fulfill. Все дальнейшие запросы блокируются; JavaScript и service workers
отключены. Формы не отправляются, клики не выполняются, input values не извлекаются.
Нет авторизации, cookies посетителей, CAPTCHA обхода или сторонней аналитики.
Скриншоты показывают изолированное представление, не полную живую страницу:
внешние картинки, CSS, JS-виджеты могут отсутствовать. Сохраняется оригинальный HTML.

PDF скачиваются только по обнаруженным внутренним ссылкам с расширением .pdf;
ссылки на другие документы сохраняются без загрузки. Текст извлекается pypdf
в отдельном процессе с лимитом времени, CPU и памяти (Linux). Если хотя бы одна
страница не даёт текста, требуется визуальная проверка, включая смешанные PDF.
Пустой текст не означает отсутствие документа и не является нарушением.
Ошибочный/зашифрованный PDF сохраняется, если он был доступен, но extraction_status
становится failed с причиной. OCR и анализ изображений не выполняются.

## Ограничения интерпретации и хранения

Реквизиты выделяются эвристически из именованных блоков, с сохранением исходного
текста и URL. ИНН/ОГРН не проверяются по реестрам и могут быть неверно сопоставлены;
identity_verified всегда false, несколько операторов поддерживаются отдельно.
Поля формы, checkbox и ссылки — только наблюдения, без вывода о правомерности.
Неизвестное назначение формы остаётся null. Отсутствие доступного артефакта
отмечается причиной; оно не заменяется предположением.

Не покрываются динамические формы вне HTML, документы без расширения .pdf,
внешние домены документов, OCR и содержимое iframe. Сайт может меняться: порядок
обхода воспроизводим, но не обещается совпадение байтов и времён между запусками.
Отдельные URL после redirect могут приводить к одному содержимому; повторяющиеся
обычные ссылки и фрагменты не увеличивают очередь. Время — UTC с часовым поясом.

Не выполняйте массовое сканирование. Используйте только публичные материалы
организации. HTML и изображения могут содержать публично опубликованные данные
сотрудников или отзывы: автоматического обезличивания нет. Не используйте сессии
посетителей; перед передачей или хранением реального досье нужна проверка состава
данных и политика доступа/удаления. Репозиторий и тесты содержат только синтетику.

## Статусы и представления артефактов (дополнительная проверка PR #2)

`CollectedEvidence.status` различает `complete`, `partial` и `unavailable`.
`partial` означает, что хотя бы один артефакт сохранён, но этап сбора завершился
ошибкой. Он имеет `available=true`, список `collection_errors` и не утверждает,
что страница недоступна. `unavailable` используется только при отсутствии
сохранённых артефактов, с причиной в `unavailable_reason`. `complete` требует
всех обязательных артефактов. Целостность сохранённых файлов проверяется при любом статусе.

При ошибке PNG, записи текста или скриншота формы сохраняются остальные артефакты,
сведения о формах и найденные ссылки; обход и загрузка PDF продолжаются.
При ошибке рендеринга оригинальный HTML сохраняется как частичное доказательство.
PDF, который сохранён, но не удалось извлечь, тоже получает `partial`; PDF без
текстового слоя остаётся доступным документом, требующим визуальной проверки.
Запись артефактов выполняется через временный файл с атомарным переименованием.

Каждый артефакт имеет явное `representation`:

- `original_html` — байты полученного HTML-ответа, до браузерного отображения;
- `extracted_text` — производный видимый текст из изолированного DOM;
- `isolated_screenshot` — производный PNG страницы или формы;
- `original_pdf` — байты загруженного PDF.

Каждый PNG содержит в JSON обязательную `notice`: JavaScript и внешние ресурсы
отключены; изображение не является точным воспроизведением живого сайта.
Эта пометка относится и к скриншотам форм. Оригинальный HTML не подменяется
изменённым браузерным DOM или текстовой выжимкой.

URL с управляющими символами, некорректным портом, credentials (включая пустые),
процентно-кодированным или scoped hostname отклоняются. Unicode-пути и query
кодируются в UTF-8; DNS-имена нормализуются IDNA. Каждый redirect повторяет DNS-проверку.
Неоднозначные Content-Length, отрицательные длины, сочетание Transfer-Encoding
с Content-Length и неподдерживаемые кодировки блокируются. Chunked и ответы без
Content-Length читаются с теми же лимитами, включая общий бюджет и крайний срок.
