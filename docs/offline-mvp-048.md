# Офлайн-цепочка №48

Новый маршрут отделён от `lexradar mvp`, `commercial_preview` и `review_bundle`: эти существующие режимы создают **внутренние** demo/review материалы, в том числе при HOLD. Их поведение сохранено. Для КП с обязательным коммерческим фильтром используйте новый маршрут:

```bash
python -m lexradar.offline_mvp \
  /path/to/saved-dossier /path/to/recorded-responses.json \
  /tmp/lexradar-048-new-run --pdf
```

Каталог результата должен отсутствовать. При необходимости задайте `--font /path/to/font.ttf`; по умолчанию используется существующий FreeMono. Нужны зависимости проекта, включая pypdf. Команда не собирает сайт: принимает проверенное сохранённое досье существующего сборщика. Ни ключи, ни HTTP-транспорт ей не нужны.

JSON ответов содержит ключи `A` и `B`, значения соответствуют `AIAuditorResult`. Это записанные/синтетические ответы, **не реальные inference**. DeepSeek/Qwen закреплены как роли профиля; актуальная доступность model IDs не проверялась. Отсутствующий B фиксируется ошибкой аудитора и даёт HOLD.

Выполнение: повторная проверка оригиналов → параллельные независимые A/B с разными system prompts → существующие валидатор и compare → консервативный коммерческий фильтр → только при GO fake proposal-stage → проверка структуры/хешей/находок → HTML и необязательный PDF. Модуль предоставляет `ProposalProvider.generate(request)` для будущего адаптера OpenRouter; реальный транспорт не реализован и не включён.

`run.json` содержит хеши досье/пакета, результаты и логи A/B, сравнение, коммерческое решение с причинами, статус КП. Отдельный `analysis/` содержит стандартный отчёт общего оркестратора. При HOLD статус КП `not_requested`, каталога `client/` нет. При ошибке генерации/проверки/рендера статус `blocked`. При успешной проверке `client/` содержит `proposal.json`, `proposal.html`, при `--pdf` также `proposal.pdf`.

Коммерческий GO требует двух успешных результатов, полной воспроизводимой локальной текстовой выборки, отсутствия предупреждений сборщика и расхождений, покрытия всех направлений, общей существенной потенциальной находки с одинаковым фактом и точной цитатой в оригинале. Полнота локального досье не означает полноту обследования сайта. GO разрешает только синтетическую подготовку предложения об экспертной проверке контекста; юридический production статус остаётся HOLD.

Для минимального MVP генератор выбирает только уже допустимые ID находок и фиксированную услугу `context_review`. Произвольные рекламные утверждения, цены, сроки, новые цитаты и подтверждение нарушения не входят в контракт и отклоняются. Это ограниченное КП с наблюдениями и предложением экспертной проверки; полноценная коммерческая редактура требует следующего этапа.

`bind_review(client_dir, reviewer)` создаёт локальную `ReviewBinding` по совокупному SHA256 фактических байтов JSON/HTML/PDF. `review_matches` пересчитывает байты: изменение любого документа инвалидирует привязку; подмена `sha256.json` не помогает. Полученную модель можно сохранить через `model_dump_json()`. Это запись о локальной версии для просмотра, без аутентификации согласующего. `authenticated=False`, автоматическая отправка и клиентский выпуск остаются запрещены. Хеш не доказывает происхождение документов и не заменяет подпись/доверенное согласование.

## Воспроизведение из Git (публикация №49)

Досье и результаты `runs-048/` в Git не публикуются. Команда выше требует
собственные локальные входные данные. Полностью синтетический GO/HOLD,
CLI и PDF воспроизводятся тестами без этих каталогов и без сети:

```bash
python -m pip install -e '.[dev]'
python -m pytest -q tests/test_offline_mvp_048.py tests/test_auditors.py \
  tests/test_mvp.py tests/test_decision.py tests/test_gateway.py tests/test_contracts.py
```

Требуется Python 3.12+ и FreeMono по пути
`/usr/share/fonts/truetype/freefont/FreeMono.ttf` (в Debian/Ubuntu пакет
`fonts-freefont-ttf`). Установка зависимостей требует сети; сами новые тесты
блокируют DNS, socket connect и OpenRouter transport. Fixtures из
`tests/test_auditors.py` создают временное синтетическое досье; новые тесты
формируют ответы A/B в памяти, CLI-тест записывает их во временный JSON.
