# Статические механизмы сбора данных (PR #12)

`lexradar primary-audit DOSSIER --output OUTPUT` повторно исследует проверенный
сохранённый HTML без браузера, JavaScript, DNS, сетевых запросов или отправки форм.
Результат всегда HOLD / not_confirmed; выпуск клиенту запрещён.

## Структуры и экспорт

- `StaticDeclaration` / `declarations.json`: каждое вхождение с типом, исходным
  значением (HTML entities сохраняются), безопасно нормализованным значением,
  evidence ID, URL страницы, SHA-256 оригинала и диапазоном исходника. Диапазон
  атрибута включает имя/кавычки, значение сохранено отдельно. Координаты: декодированный
  UTF-8, строка от 1, столбец от 0, исключительная конечная граница.
- `FormMechanism` внутри `forms.json`: method, отдельные ссылки на HTML action,
  альтернативные data-маршруты, ограниченные JS-кандидаты и обработчики, имена
  скрытых полей. Значения полей не сохраняются. Фактические маршрут и получатель unknown.
- `PopupRelation` / `popup-relations.json`: ссылки на trigger/target, уникальность
  идентификатора, эвристические кандидаты политики/согласия/контактной формы/записи,
  отдельные диапазоны доступного текста для классификации. Объявленная связь не
  подтверждает отображение, доступность или юридическую достаточность документа.
- `IntegrationGroup` / `integration-groups.json`: группа по безопасному URL, все
  отдельные вхождения сохраняются. Query, повторные параметры, fragment и percent
  escapes не удаляются; регистр схемы/хоста и стандартный порт нормализуются.
  Динамический полный URL неизвестен и не группируется по одному literal prefix.

Восемь прежних экспортов сохраняются, добавлены три новых. Старые результаты
читаются с пустыми дополнительными списками; production-поля не изменены.

## Границы распознавания

Лексический анализ inline JS ограничен 32768 символами/4096 токенами: literal
`object.src = 'https://...'` (динамическое продолжение отмечается отдельно), точный
`document.querySelector('#id')`/`$('#id')` и submit callback `function`, literal
fetch/ограниченный ajax URL внутри него. Дубли id исключают привязку маршрута.
Комментарии, quoted examples, template strings и regex/division ambiguity не
интерпретируются; неоднозначный суффикс не исследуется. Это не JS AST и не доказательство
исполнения; aliases, minified bundles, computed URLs и внешние JS не исследуются.

GTM, GA, Метрика, Карты классифицируются отдельно по объявленному адресу. Также
сохраняются noscript iframe, script/iframe src, lazy data-src и кандидаты библиотек
форм. Шаблоны исключены; noscript декларация не подтверждает её отображение.

Лимиты: 1000 деклараций и 300 id-кандидатов на страницу, 4096 символов значения,
8192 символа классифицируемого текста popup. Превышение ограничений не расширяет
доказательную область; причины сохраняются. HTML partial/unknown наследуются;
отсутствие находки не доказывает отсутствие механизма. Повторяющиеся ссылки создают
одну задачу/гипотезу по группе страницы, а не новые коммерческие возможности.

Приватный пилот выполняется отдельно: исходный HTML, досье и подробные результаты
не включаются в коммиты. Реальная сеть, cookies, фактический получатель, работоспособность
интерфейса, прочтение внешних документов и юридическая оценка требуют отдельного этапа.
