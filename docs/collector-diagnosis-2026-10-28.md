Источник: runs/experiment-ignore-robots-2026-10-28-fixed-https/diagnosis.md и сохранённые HTML, collection.json, crawl/requests.jsonl. Сеть и массовый запуск не использовались.

Подтверждены и исправлены два дефекта:

- Строка 30, zrenie-v-tule.ru: корректный SVG `<animate .../>` отсутствовал в списке допустимых самозакрывающихся SVG-элементов StaticText. На первом animate (строка HTML 1406) парсер удерживал весь последующий текст. Добавлен только animate в существующий список; вне SVG этот тег по-прежнему вызывает ограничение. Повторный разбор сохранённого HTML даёт 28949 символов до нормализации пробелов, без структурных ограничений.
- Строка 25, dentistry-dk.ru: ссылка /img/priem-ruk.jpg попадала в очередь HTML и занимала пятую попытку. Очередь теперь пропускает явно обозначенные изображения по расширению пути, включая верхний регистр и URL с query. Документы и HTML остаются в прежнем порядке. Это улучшение будущего охвата, не новые доказательства нарушения.
