# LexRadar run 140 — public review bundle

Free static screening of the first 15 unique eligible sites from `clinics_full.csv`. No OpenRouter, Single Auditor, approvals, or client sending were used.

`summary.csv` and the 15 files in `diagnostics/` give per-site status, elapsed time, bounded crawl diagnostics, and draft availability. Raw page captures, dossiers, cookie extracts, provider data, and the full source CSV are intentionally excluded.

The Grandmed HTML/PDF are draft copies. The proposal’s seller phone and email were removed before publication; the original local audit result was not changed. Absence of a consent marker in static markup is reported only as an observation, not as a proven violation.
