# LexRadar №146 — локальная проверка интеграции prepare → screening → КП

## Что изменено

`prepare` теперь после сбора вызывает имеющийся локальный `rank` и генератор КП. Отдельный CLI-режим `screening-draft` удалён; повторный сетевой сбор не выполнялся. `prepare` сохраняет обычный evidence packet, а при недоступных материалах и частичном пакете сохраняет HOLD/причину и нейтральный черновик. Сбой одного лида не прерывает обработку следующих. Отправка отключена, ручное утверждение обязательно.

## Результаты по сохранённым данным №145

Обработано 10 сохранённых досье без сетевых запросов: 6 SUCCESS, 3 SKIPPED, 1 PARTIAL, ошибок генерации нет. Сбор №145 содержал 30 попыток страниц и 26 сохранённых HTML. Три пропуска вызваны ограничением robots.txt или неполным redirect; один пакет превышал лимит 200 000 байт, поэтому помечен PARTIAL и не обрезался. Для каждого лида сформирован локальный HTML/PDF: 10/10. Локально получено 3 риск-ориентированных черновика и 7 нейтральных; риск-ориентированные опираются на наличие формы и типы полей, не подтверждают нарушение и требуют проверки. В `summary.csv` опубликованы обезличенные агрегаты.

В публикацию включены семь нейтральных HTML/PDF примеров. Три риск-ориентированных HTML не публикуются: неизменённый шаблон, закреплённый как v2.4 по хэшу, содержит видимый ярлык «КП v2.2» и фиксированное утверждение об экспресс-аудите для организаций Калужской области. Это не соответствует скринингу этих организаций и может создать ложное впечатление. Текст шаблона не менялся; эти черновики остаются только локальными и не утверждены к отправке.

## Запуск для новой партии

```bash
python -m lexradar.mvp_batch leads.csv --output runs/output --mode prepare --max-sites 10 --max-ai-calls 0 --allow-site-collection
```

Команда использует только бесплатный сбор/локальные правила; `--allow-site-collection` разрешает сетевое чтение сайта по действующим ограничениям. Перед отправкой КП требуется отдельное ручное утверждение.

Сводка и безопасные примеры находятся рядом с этим отчётом. Публичная папка не содержит досье, исходный CSV, ответы провайдера или внутренний manifest.
