# Синтетический первичный аудит

Это локальные учебные артефакты, **не сбор реального сайта**. `dossier/collection.json`
совместим с Collector, оригинальный HTML и его производный текст сохранены с SHA-256.
Однопиксельный PNG — только фикстура целостности, а не screenshot формы или живого сайта.
ООО вымышлены, домены `.example`; никаких форм или ссылок в примере не посещали.

`result/` содержит восемь внутренних файлов команды `lexradar primary-audit`.
Две формы явно упоминают разные организации. Это кандидаты ролей, не подтверждённые
операторы. Истинные получатели и сетевые маршруты неизвестны. Цены, лицензия,
доступность политики и правовые основания требуют дополнительной проверки.

`incomplete/dossier/` содержит валидное пустое досье; `incomplete/audit.json`
демонстрирует неполный результат без придуманных наблюдений и коммерческих работ.
Техническая обработка завершена, юридическое исследование — нет. Оба результата HOLD;
клиентский выпуск и отправка запрещены.

`partial/dossier/` — синтетический HTML с повреждением внутри формы.
`partial/forms.json` содержит только поле телефона до границы остановки, статус partial,
причины и точные координаты. Поздние email и ссылка на согласие не обследованы;
их отсутствие в матрице не означает отсутствие в исходном HTML. В `result/forms.json`
обе исходные корректно закрытые формы имеют complete; это только полнота статического
разбора. Старые JSON без `static_coverage` читаются как unknown.

```bash
lexradar primary-audit examples/primary-audit/dossier --sector medical \
  --as-of 2026-10-10T00:00:00Z --output work/primary-example
lexradar primary-audit examples/primary-audit/incomplete/dossier \
  --as-of 2026-10-10T00:00:00Z --output work/primary-empty-example
```

[Механизмы и ограничения](../../docs/primary-audit-methodology.md).

После PR #11 примеры сохраняют `source_origin=unknown`: их старые метаданные не
аутентифицируются и не переобозначаются автоматически как Collector. Отдельные
экспорты содержат происхождение и статические ограничения материалов. Частичная
форма по-прежнему сохраняет только префикс, поскольку ошибка находится внутри неё.
[Восстановление и диапазоны доказательств](../../docs/resilient-html-evidence.md).
